# Periodic Instruments — Element Descriptions (Draft)

Draft roster of all 94 elements (H through Pu), **grouped by IUPAC chemical group (column)**.  
Each entry is derived from the element's **emission-light frequencies** and **chemical properties**. Elements in the same group share a recognizable timbral family resemblance, but no two elements sound identical.

Columns:
- **Sound** — base timbre / synthesis character.
- **Signature FX** — default effects chain.
- **Human feel / production use** — where and how it tends to be used musically.

---

## Group 1 — Alkali Metals (H, Li, Na, K, Rb, Cs, Fr)

Family resemblance: bright, plucky, highly reactive voices with fast transients and a "salty" top end. Heaviness and warmth increase down the group as atomic mass grows. (Hydrogen is a nonmetal outlier but shares the group's high, airy register.)

| Element | Sound | Signature FX | Human feel / production use |
|---|---|---|---|
| Hydrogen (H) | Airy high sine pad with sparse harmonics (alkali-like openness) and a bright, reactive halogen-like edge | Shimmer reverb, high-pass | Ethereal top-end layers, ambient beds, and sharp transient accents (dual nature) |
| Lithium (Li) | Bright pluck, light and quick | Short plate reverb | Indie/electronic hooks, staccato lines |
| Sodium (Na) | Salty bright pluck, slightly warmer than Li | Spring reverb | Funky bass lines, plucky chords |
| Potassium (K) | Soft warm keys, rounded transients | Tape saturation | Piano-like chords, singer-songwriter beds |
| Rubidium (Rb) | Deeper pluck, warmer midrange | Plate reverb, light chorus | Retro synth bass, warm arpeggios |
| Cesium (Cs) | Heavy warm pluck, slow-ish decay | Tape saturation, delay | Down-tempo bass, mellow hooks |
| Francium (Fr) | Darkest, heaviest alkali pluck | Saturation, long plate | Rare, unstable low-end stabs |

### Lanthanide series (Ce–Lu)

Family resemblance: rare-earth shimmer and glow; members sound closely related (shared f-electron character) but each has a distinct harmonic "color" from its emission lines.

| Element | Sound | Signature FX | Human feel / production use |
|---|---|---|---|
| Cerium (Ce) | Bright reactive rare-earth; fast formant sweep on attack | Chorus, delay | Reactive leads, shimmering textures |
| Praseodymium (Pr) | Greenish rare-earth; formant peak in upper mids | Delay, shimmer | Colorful leads, glassy pads |
| Neodymium (Nd) | Magnetic, focused tone; pitch glide toward nearest harmonic | Chorus, plate reverb | Focused leads, "pulled" resonance |
| Promethium (Pm) | Radioactive, rare; granular instability and pitch drift | Granular, distortion | Unstable FX, experimental beds |
| Samarium (Sm) | Warm dark rare-earth; slow filter movement | Plate reverb, saturation | Moody beds, evolving pads |
| Europium (Eu) | Red-glowing rare-earth; shimmering formant peak | Shimmer reverb | Glowing leads, formant shimmer |
| Gadolinium (Gd) | Strong magnetic; deep resonance and slow glide | Chorus, reverb | Cinematic pads, magnetic pull |
| Terbium (Tb) | Green-glowing; bright spectral peak and fast LFO | Shimmer reverb, delay | Sparkly leads, bright arps |
| Dysprosium (Dy) | Heavy magnetic; dark low resonance | Saturation, low-pass | Heavy beds, dark drones |
| Holmium (Ho) | Highest magnetic strength; extreme resonance/pull | Delay, chorus | "Attracted" resonance, tight leads |
| Erbium (Er) | Pink-glowing; soft formant shimmer | Shimmer reverb | Pink pads, gentle leads |
| Thulium (Tm) | Blue-glowing; cool airy spectral shift | Delay, reverb | Cool pads, airy leads |
| Ytterbium (Yb) | Soft heavy rare-earth; slow decay, warm saturation | Plate reverb, saturation | Soft pads, warm beds |
| Lutetium (Lu) | Densest lanthanide; polished top end, tight harmonics | Shimmer reverb | Polished leads, dense top end |

## DSP Parameter Mapping

Chemical properties map to DSP parameters (see README concept for full list):

| Property | DSP parameter |
|---|---|
| Atomic mass | Fundamental pitch, decay length, "weight"/low-end |
| Electronegativity | Filter brightness/aggression, attack speed |
| Reactivity | Envelope speed, probability of random modulation |
| Radioactivity | Granular processing, random LFO, pitch instability |
| Magnetism | Resonance, pitch glide, harmonic "attraction" |
| Emission color (glow) | Spectral shift / formant (artistic marker) |
| Valence | Harmonic count / layer count |

## Metaphor → DSP Translation

| Metaphor (in roster) | DSP treatment |
|---|---|
| Salty (Na) | Light high-frequency saturation + narrow upper-mid peak |
| Toxic (As, Cd) | Distortion with resonant filter |
| Glowing colors (lanthanides) | Formant/spectral peak shift |
| Magnetic (Nd, Gd, Dy, Ho) | Resonance depth, pitch glide, harmonic "attraction" |
| Radioactive (Pm, Tc, Po, U, Pu, ...) | Granular, random LFO, pitch instability |
| Liquid/flowing (Hg, Ga) | Portamento/glide, phaser/flanger |
