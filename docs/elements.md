# Periodic Instruments — Element Descriptions (Draft)

Draft roster of all 94 elements (H through Pu), **grouped by IUPAC chemical group (column)**.  
Each entry is derived from the element's **emission-light frequencies** and **chemical properties**. Elements in the same group share a recognizable timbral family resemblance, but no two elements sound identical.

Columns:
- **Sound** — base timbre / synthesis character.
- **Signature FX** — default effects chain.
- **Human feel / production use** — where and how it tends to be used musically.
- **Orchestral color** — instrument + articulation + register (specific, not generic).

---

## Group 1 — Alkali Metals (H, Li, Na, K, Rb, Cs, Fr)

Family resemblance: bright, plucky, highly reactive voices with fast transients. Heaviness and warmth increase down the group. Hydrogen is a single instrument with a **dual mode** (alkali-like / halogen-like).

| Element | Sound | Signature FX | Human feel / production use | Orchestral color |
|---|---|---|---|---|
| Hydrogen (H) | Airy high sine pad with sparse harmonics (alkali-like openness) and a bright, reactive halogen-like edge | Shimmer reverb, high-pass | Ethereal top-end layers, ambient beds, sharp transient accents (dual mode) | Piccolo harmonics, flutter-tongue, high register |
| Lithium (Li) | Bright pluck, quick decay, upper-mid emphasis | Short plate reverb | Indie/electronic hooks, staccato lines | Pizzicato violin, sul ponticello, high |
| Sodium (Na) | Salty bright pluck: light HF saturation + narrow upper-mid peak | Spring reverb | Funky bass lines, plucky chords | Muted trumpet, staccato, mid-high |
| Potassium (K) | Soft warm keys, rounded transients, gentle saturation | Tape saturation | Piano-like chords, singer-songwriter beds | Warm piano, una corda, mid |
| Rubidium (Rb) | Deeper pluck, warmer midrange, chorus shimmer | Plate reverb, light chorus | Retro synth bass, warm arpeggios | Cello pizzicato, mid register |
| Cesium (Cs) | Heavy warm pluck, slow decay, tape warmth | Tape saturation, delay | Down-tempo bass, mellow hooks | Double bass pizzicato, low register |
| Francium (Fr) | Darkest, heaviest alkali pluck, saturated low-end | Saturation, long plate | Rare unstable low-end stabs | Contrabass, col legno, low |

## DSP Parameter Mapping

Chemical properties map to DSP parameters:

| Property | DSP parameter |
|---|---|
| Atomic mass | Decay length, low-end weight, sub amount, density (pitch stays in musical range via octave-constrained mapping) |
| Electronegativity | Filter brightness/aggression, attack speed |
| Reactivity | Envelope speed, probability of random modulation |
| Radioactivity | Granular processing, random LFO, pitch instability |
| Magnetism | Resonance, pitch glide, harmonic "attraction" |
| Emission color (glow) | Formant/spectral shift with direction: greenish = upper-mid peak, red = low-mid warmth, blue = high airy shift, pink = soft formant shimmer |
| Valence | Harmonic count / layer count |

## Metaphor → DSP Translation

| Metaphor (in roster) | DSP treatment |
|---|---|
| Salty (Na) | Light high-frequency saturation + narrow upper-mid peak |
| Toxic (As, Cd) | Distortion with resonant filter |
| Glowing colors (lanthanides) | Formant/spectral peak shift (direction per color) |
| Magnetic (Nd, Gd, Dy, Ho) | Resonance depth, pitch glide, harmonic "attraction" |
| Radioactive (Pm, Tc, Po, U, Pu, ...) | Granular, random LFO, pitch instability |
| Liquid/flowing (Hg, Ga) | Portamento/glide, phaser/flanger |
